# PayForWhat Trademark Policy

The PayForWhat software is open source. The project's identity is separate from the
software license.

This policy applies to the **PayForWhat** name, project logos, distinctive
official-service branding, and other identifiers used to distinguish the official
project and its hosted distributions. It does not claim that any mark is registered, and
it claims no rights beyond those available under applicable law.

The CC BY 4.0 notice above applies to the text of this policy, not to the marks
described by it. Neither AGPL-3.0-only nor CC BY 4.0 grants trademark rights.

## Uses that do not require permission

You may:

- Refer truthfully to the PayForWhat project
- Link to the official repository or hosted service
- Discuss, review, compare, teach, or report on the project
- State that software is compatible with PayForWhat
- State that a fork is “based on PayForWhat” or “derived from PayForWhat”
- Retain notices required by the applicable software or documentation license

These uses must not imply sponsorship, endorsement, partnership, or official status.

## Forks and redistributed versions

You may use, modify, and host the software under AGPL-3.0-only. If the result is not an
official PayForWhat distribution, you should:

1. Give the product or service a clearly different primary name.
2. Remove PayForWhat logos and official-service visual identifiers.
3. Avoid domains, account names, package names, or presentation likely to make users
   believe the distribution is official.
4. Describe the relationship accurately, for example: “Based on the PayForWhat
   open-source project.”
5. Preserve copyright and license notices without presenting them as branding.

## Uses that require permission

Ask the project maintainers before:

- Using PayForWhat as the primary name of another product, service, company, or hosted
  distribution
- Using a PayForWhat logo as another project's logo or application icon
- Selling merchandise that features the project's marks
- Registering a confusingly similar domain or social account for a related service
- Claiming to be an official, certified, sponsored, or endorsed distribution

Permission may be requested through the contact channels published in the official
repository. The marks are currently controlled by the repository owner, `m0p4rk`. Submit
a public
[trademark permission request](https://github.com/m0p4rk/PayForWhat/issues/new?template=trademark_permission.yml)
when the proposal contains no confidential information. A public request is not
permission; only an explicit response from the rights holder grants it.

For a request that genuinely requires confidentiality, use the repository's
[private report form](https://github.com/m0p4rk/PayForWhat/security/advisories/new) and
prefix the title with `Trademark:`. This use of the confidential channel does not imply
that the request is a software vulnerability.

## Third-party marks

Names and marks of services mentioned in PayForWhat research or documentation belong to
their respective owners. They are used only to identify the services being discussed.
Their appearance does not imply affiliation or endorsement.

## Questions

If you are unsure whether a proposed use could confuse users about its source, ask
before using the mark. This policy is not legal advice.
